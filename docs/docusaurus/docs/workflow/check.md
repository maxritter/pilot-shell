The change is checked by an AI that did not write it, then you decide.

| Step | What happens |
| --- | --- |
| **[Verify](check/verify.md)** | The real program is checked against your Done means, with evidence |
| **[Review](check/review.md)** | You and your team see what was checked, try it, read the diff, and you decide |
| **[Shipped](check/shipped.md)** | The task keeps its record; merging and deploying stay with you |
| **[When it stops](check/stops.md)** | Three failed rounds stop for you; any task can be abandoned |
