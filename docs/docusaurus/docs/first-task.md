Pick a medium-sized feature in a repository you know. Your agent asks each decision in the App, and its terminal shows a single line while it waits. Keep the App open beside your agent.

1. **Describe it.** Click **+ New** in the App, say what you want and copy the command it gives you. Or type `/ql add a CSV export to the reports page` in your agent (`$ql` in Codex).
2. **Answer its questions.** Your agent reads the code and groups independent questions together into one batch. Research then reads the code and may ask one more batch of choices the code leaves open; a clear task has none. **Your turn** shows one focused question; use **Skip for now** to answer another first. Click a choice, write in **Your own answer** and press **Send**, or ask it to tell you more. Each answer goes to the agent immediately.
3. **Approve the Plan.** Settle any **Your call** inside it, then read the complete Plan and its proposed **Done means**. Your agent handles technical review findings. When the Plan is ready, use **Approve Plan** or **Give feedback** in its header.
4. **Start Implement.** While you read the Plan, your agent cuts it into slices in the Outline, which needs no approval. Implement then opens with your Build defaults and one command to copy.
5. **Agents build and check.** Your agent works on its own until the final review. Implement shows **Build**, with the slices, changes and checks as they happen.
6. **Settle what is left.** Confirm what only you can, and look at the result.
7. **Approve the change.** Approve, and the pull request opens with its proof.
