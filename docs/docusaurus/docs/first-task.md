Pick a medium-sized feature in a repository you know. Opus 5.5 is recommended for this session.

1. **Describe it.** `/ql add a CSV export to the reports page` (`$ql` in Codex).
2. **Answer its questions.** Your agent reads the code, then asks one question at a time, each with its recommendation. The task appears in the App as soon as it starts.
3. **Approve the Plan.** Open it in the App. Try the mockup, select any line or diagram to comment, then press **Request changes** or **Approve**.
4. **Start Implement.** The App shows a prompt such as `/ql implement csv-export` with a **Copy** button. Start a fresh session your own way, Sonnet 5.5 recommended, and paste it.
5. **Follow the build.** Each task starts with a failing test. It asks you only for a decision that is yours.
6. **Read the check.** An AI that did not write the code checks every point of your Done means and keeps the evidence.
7. **Approve the change.** Try it, read the diff, then press **Approve and ship**. **Create pull request** opens the pull request when you click it.
