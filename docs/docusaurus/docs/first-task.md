Pick a small feature in a repository you know.

1. **Describe it.** `/ql add a CSV export to the reports page` (`$ql` in Codex). Your agent suggests a route and gives you the Cockpit link.
2. **Approve the frame:** the problem and **Done means**, the numbered results you will accept the change by.
3. **Approve the research, then the design.** Each has its own approval. You can read and comment from the first draft; **Approve** unlocks when your agent says the document is ready. Try the mockup. Select a passage to comment, then press **Request changes** or **Approve**.
4. **Approve the outline:** the slices, and everything you must settle before the build, such as a login or a permission.
5. **Hand off.** Pick who builds, run the launch steps, paste the build prompt.
6. **Follow the build.** It asks you only when a check keeps failing or a decision is yours.
7. **Review the change.** See what was checked, try it, read the diff, then press **Approve and ship**.
