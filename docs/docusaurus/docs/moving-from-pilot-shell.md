Pilot Shell is now QualityLayer, and the move asks you nothing. Pilot Shell's updater, the App or the installer moves a machine over. `/spec` is now `/ql`, and the Console is the QualityLayer App.

![Moving from Pilot Shell 11: your licence, plans and own files carry over; Pilot Shell's own parts are removed; the tools it installed and its memories stay](pathname:///img/diagrams/move-light.svg)
![Moving from Pilot Shell 11: your licence, plans and own files carry over; Pilot Shell's own parts are removed; the tools it installed and its memories stay](pathname:///img/diagrams/move-dark.svg)

- **Carries over:** a paid licence, every plan in `docs/plans/`, and your own settings, skills and files. A Pilot Shell trial becomes a 7-day QualityLayer trial.
- **Removed:** only what Pilot Shell added to your agents and shell.
- **Stays:** the tools Pilot Shell installed and its memories in `~/.pilot`. QualityLayer does not need them; ask your agent to remove what you no longer use.
