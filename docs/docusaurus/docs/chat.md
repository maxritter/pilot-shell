Use **Chat** for a direct conversation with **Claude Code or Codex**, without workflow steps or approval gates.

![Chat workspace with the conversation, saved plan, Tasks and composer; illustrative data](pathname:///img/app/chat-dark.png)

*Illustrative task, shown in the full workspace.*

## Start a Chat {#start}

Choose **+ New → Chat**, pick your project and describe what you need. **Conversation** and **Terminal** show the same session. Return to the same task to keep its history.

## Questions and tasks {#questions}

Supported questions appear above the composer. Pick a numbered choice or type your answer. When the agent reports a task list, open **Tasks** to see its progress.

Outside Codex sessions are read-only here; answer in Codex's terminal.

## Add what you need {#tools}

Ask your agent to save a plan, make artifacts, build in slices, run checks or request an independent review. Saved plans open in the Reader; artifacts open in their viewer. Your agent runs the checks and shows their results.

## Start the workflow {#start-the-workflow}

Choose **Start the workflow → Feature or Bugfix** for the structured process. The same task enters Discuss with its conversation and saved work as context. You approve the workflow Plan before later implementation. Let active slice helpers finish or stop them first.

Chat does not support team sharing.
